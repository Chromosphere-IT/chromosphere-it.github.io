Support

Fragen, Fehler oder Feedback? Schreib an ckdevel@me.com. Bei Fehlern hilft: Spielversion, ob Gerät oder Simulator, und was gerade passiert ist.

Scores für die Bestenliste gehen nicht an diese Adresse, sondern wie im Spiel beschrieben an score@crankoid.de.

Datenschutz

Das Spiel selbst überträgt nichts. Nur wenn du deinen Score freiwillig per E-Mail einsendest, werden Daten verarbeitet. Details in der Datenschutzerklärung.

Support (English)

Crankoid is a crank-controlled brick breaker for Playdate with procedurally generated levels, a daily challenge and a world leaderboard. Download on itch.io · Leaderboard

Questions, bugs or feedback? Write to ckdevel@me.com. For bugs, please include the game version, device or simulator, and what happened.

Leaderboard scores do not go to this address but to score@crankoid.de, as described in the game.

The game itself transmits nothing. Data is only processed if you voluntarily email your score. See the privacy policy.
